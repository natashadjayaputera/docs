# Natasha Djayaputera

Install dependencies with `bun install --frozen-lockfile` and start the local site with `bun run dev`.

- `/docs/cv` — English CV
- `/docs/rireki` — 履歴書 (Japanese résumé)
- `/docs/shokumu` — 職務経歴書 (Japanese work history)

Each route supports printing to A4 or saving as PDF from the browser's print dialog. Use 100% scale and disable browser headers and footers.

Run `bun run build` to check and build the static site in `dist/`.
